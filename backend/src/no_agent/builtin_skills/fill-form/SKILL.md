# 填写网页表单

不要截图、逐个点击字段。先一次读出全部字段，再一次填完。

## 何时使用

用户要在某个网页上填写或提交表单，可以给出网址和要填的信息。

不适用：需要上传文件、验证码、多页向导式流程。

## 参数

- `url`：表单页面网址；不填则使用浏览器当前页面
- `data`：用户已提供的要填写的信息（对象或自然语言文本）
- `submit`：填完后是否提交，默认是（提交前一定会请求用户确认）
- `scope`：可选，限定表单所在区域的 CSS 选择器

## 步骤

1. **打开页面**：有 `url` 就打开。
2. **读取全部字段**：一次拿到每个字段的标签、类型、是否必填、下拉选项、当前值，以及每个按钮是否是提交按钮。跳过 `file` 和 `password` 字段。
3. **对应已知信息**：把用户给的信息对应到字段。只填有明确依据的值，不确定就不填，绝不编造。下拉框和单选用选项文字，复选框用 true/false。
4. **一次问完缺失项**：把还没有值的必填字段合并成一次提问，不要一个个问。
5. **批量填写**：一次填入所有值。
6. **回读校验**：逐个读回字段值，和要填的值对比。不一致就停下，不要提交。
7. **确认后提交**：把"字段: 值"的摘要给用户确认，用户同意后再点击提交按钮。用户不同意就结束，不要重试。

## 注意

- 选择器优先用 `#id`，其次是 `[name=...]`、`[aria-label=...]`，最后才用层级路径。这样页面小改版后依然有效。
- 提交是不可撤销操作，必须经用户确认。

## 自动执行

本技能带有可直接执行的流程脚本 `scripts/flow_v1.py`，由 No-Agent 运行。失败时由 AI 接管，并自动修补脚本。
